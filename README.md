# Student Management System in C

A console-based **Student Management System** built using C programming to manage student records efficiently with persistent file storage.

## Features
- **Add Student Record:** Store student details including Roll Number, Name, Course, and Contact Number.
- **Display All Records:** View all saved student records in a structured format.
- **Search Student:** Quickly find a student's record by Roll Number.
- **Update Student Record:** Modify existing student information.
- **Delete Student Record:** Remove a student's record from storage.
- **Persistent Storage:** Automatically saves and loads data using file handling so records remain safe even after closing the program.

## Concepts Used
- Structures (`struct`)
- Pointers & Dynamic Memory Allocation
- Functions & Modular Programming
- File Handling (`fopen`, `fwrite`, `fread`, etc.)
